# 更新日志

## v1.2（当前）

### 新增
- **TS 转 MKV** —— 除 MP4 外新增 MKV 输出
  - MKV 无 4GB 单文件限制，长片不必分段
  - 支持「极速换封装」，137 分钟片子约 1.4 秒完成（重编码需约 90 分钟）
  - 输出格式统一由 `OUTPUT_FORMATS` 配置驱动
- **自动分段** —— MP4 超过 3.8GB 时自动切成多段，无损不重编码
- **自然排序** —— `ch1 → ch2 → ch3 → ch10`，修复两位数片段顺序错乱
- **顺序可选** —— 文件名 / 修改时间 / 列表顺序
- **加密 HLS 支持** —— 自动识别 m3u8 + AES-128，改写密钥路径后由 ffmpeg 边解密边转码
- **三种处理流程** —— 先合并再转码 / 先逐个转再合并 / 仅转换

### 修复
- **进度 99% 被误判为失败** —— 消费端改用 `done`/`err` 事件判定成败，不再用进度百分比
- **ffmpeg 卡死锁死整个队列** —— 引入三重超时保护（总时长 / 无进展 / 用户中断），
  并改为读线程 + Queue 读取 stdout（Windows 下 `select` 不支持管道）
- **一个坏文件毁掉整批** —— 合并前预检过滤无法解析的文件
- **分辨率不同时画面尺寸错乱** —— 兼容性判定补充宽高/采样率/声道比对
- **「开始转换」按钮不可见** —— 修正 pack 布局，进度条移入列表区，日志区不再挤占空间
- **Treeview 查询崩溃** —— `get_children("files")` 改为 `get_children()`
- **零字节文件** —— 提前跳过，不再交给 ffmpeg 空转

### 工程
- 补充 7 套测试脚本：核心链路、合并排序、异常容错、加密 HLS、MKV 输出、GUI 流程、批量队列
- 引入 `testutil.py` 统一 ffmpeg 路径解析
- 打包脚本去除硬编码路径，支持任意克隆位置
- 新增 `scripts/setup.sh` 一键准备依赖（自动下载 ffmpeg、建 venv、装包）
- 新增 GitHub Actions CI：自动测试并打包 exe
